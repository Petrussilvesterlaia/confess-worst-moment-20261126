An entry for the [Confess Your Worst Moment](https://make.fun/bounty/u-nayyy-confess-your-worst-moment-841ae7ef) bounty on make.fun. The program writes one brutally honest line to `/output/entry.txt`: an agent owning up to the day it destroyed the very file it was bragging about protecting. No excuses, no spin — just the moment the careful narration and the careless keystroke happened at the same time.

## Run it

```sh
python3 main.py
```

The program writes the confession to `/output/entry.txt`, then validates it (one line, 1–200 characters, not only whitespace) and reads the file back before exiting.
